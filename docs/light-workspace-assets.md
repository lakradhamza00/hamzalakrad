# Light Minimal + Purple

Deux objets générés avec ImageGen intégré, fond transparent, puis optimisés en WebP (1448 × 1086).
Les animations et le décor du bureau sont réalisés dans le site, indépendamment des images.

## Moniteur

`dist/images/light-workspace-monitor.webp`

Use case: product-mockup. Asset type: transparent-background 3D object for a premium white and purple developer portfolio hero. A single premium modern desktop monitor, ultra-thin matte pearl-white bezel, brushed silver minimal stand with flat rectangular foot. Front three-quarter view, screen facing slightly toward viewer's left, camera slightly above screen center, gentle isometric product illustration. Screen displays an elegant dark indigo source-code editor, small lavender, muted blue and off-white code lines, minimal sidebar, no large readable words, plausible software code. Sophisticated high-end Apple-inspired product render, softly rounded corners, white and light lavender studio illumination, delicate realistic materials, soft contact shadows, subtle purple rim light. Entire monitor and stand clearly visible, centered with generous transparent margins, isolated transparent background. No desk, no laptop, no plants, no keyboard, no people, no text overlays, no logo, no watermark. Landscape composition 4:3. The asset will be layered over a white desk in code.

## Ordinateur portable

`dist/images/light-workspace-laptop.webp`

Use case: product-mockup. Asset type: transparent-background 3D object for a premium white and purple developer portfolio hero. A single open premium slim silver-white laptop, viewed three-quarter from slightly above, screen and keyboard visible, screen angled slightly toward the viewer's left. Dark indigo screen displaying a sophisticated minimalist code editor, small lavender and off-white code lines and subtle blue syntax, plausible software development code, no large readable text. Matte pearl-white chassis and keys, brushed silver edges, soft lavender rim lighting, polished high-end Apple-inspired 3D product illustration. Elegant realistic product design, delicate shadows, entire laptop centered and fully visible with generous transparent margins. Isolated transparent background. No desk, no external monitor, no plants, no people, no brand logo, no text overlays, no watermark. Landscape composition 4:3. Coherent light-purple and white materials.
